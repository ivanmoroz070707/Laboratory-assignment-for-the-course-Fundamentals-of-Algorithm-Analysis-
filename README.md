# Навчальна СУБД (In-Memory Database Engine) — Варіант №5

Даний проєкт є навчальною реалізацією реляційного движка бази даних у пам'яті (In-Memory DB), написаною мовою Python. Движок підтримує власний SQL-подібний діалект із можливістю створення таблиць, додавання рядків, виконання з'єднань `LEFT_JOIN`, фільтрації `WHERE` та індексації стовпців.

---

## 1. Структура проєкту

* `main.py` — Головна точка входу, інтерфейс командного рядка (REPL) та обробка багаторядкового вводу.
* `lexer.py` — Лексичний аналізатор (токенізатор).
* `parser.py` — Синтаксичний аналізатор (парсер).
* `ast_nodes.py` — Структури даних для команд (Abstract Syntax Tree / DTO).

---

## 2. Опис інтерфейсу користувача (CLI)

Інтерфейс працює у режимі інтерактивної консолі (REPL):

* **Завершення команд:** Кожна команда має закінчуватися символом `;`. Будь-який текст у рядку після `;` ігнорується.
* **Багаторядковий ввід:** Якщо символ `;` не введено, консоль очікує продовження команди на наступному рядку (індикатор змінюється з `db>` на `...`).
* **Регістронезалежність:** Ключові слова (`CREATE`, `SELECT`, `WHERE` тощо) нечутливі до регістру. Назви таблиць, стовпців та значення в кавычках є чутливими до регістру.
* **Вихід:** Для завершення роботи з програмою введіть `EXIT;` або натисніть `Ctrl+C`.

### Підтримуваний синтаксис команд

#### 1. Створення таблиці (`CREATE`)
Створює нову таблицю з вказаними стовпцями. Для створення індексу додається прапорець `INDEXED`:
```sql
CREATE owners (owner_id INDEXED, owner_name, owner_age);

```

#### 2. Додавання даних (`INSERT`)

Додає новий рядок у таблицю (слово `INTO` є опціональним). Усі значення передаються у подвійних лапках:

```sql
INSERT INTO owners ("1", "Vasya", "30");
INSERT owners ("2", "Petya", "25");

```

#### 3. Формування вибірки (`SELECT`)

Підтримує опціональні секції `LEFT_JOIN` та `WHERE` (оператор менше `<`):

```sql
SELECT FROM owners LEFT_JOIN cats ON owner_id = cat_owner_id WHERE cat_name < "Pushok";

```
